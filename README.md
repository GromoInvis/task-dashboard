# Task Dashboard

Interactive task management client built with React, TypeScript, Redux Toolkit, and Tailwind CSS.

## Features

- Multi-criteria filtering (status, priority, assignee)
- Search across titles, descriptions, and tags
- Dynamic status tracking on a responsive kanban board
- Centralized state with Redux Toolkit slices and memoized selectors
- Strict TypeScript models, API DTOs, and component prop interfaces

## Scripts

```bash
npm install
npm run dev
npm run build
```
